# East-West-Solar-Tracking-System-
Arduino-based solar tracker that follows the sun using light sensor feedback and folds closed when it's dark.
Parts List: Arduino Uno, 28BYJ-48 stepper with ULN2003 driver, SG90 servos, LDR photoresistors, 5V 200mA Solar Panels, Dupont jumper wires, USB/Micro-USB cables, 5V power banks.
